# 代码知识图谱业务语义：方法调用

- `方法-[:接口调用]->方法` 表示 Controller 或接口入口方法分派到实现方法；关系的 `经由接口` 保存接口全限定名。
- `方法-[:调用]->方法` 表示相邻方法调用。直接上游或直接下游只匹配一条 `调用`，不得再用 `调用深度` 判断是否直接。`调用深度=0` 是接口分派的镜像，正数与对应有序路径边的 `位置索引` 一致；该属性只是原调用路径中的位置元数据。
- “上游方法”“上游调用方”“上游影响范围”表示上游可达集合：使用 `调用*1..` 判断可达性，并为每个上游方法返回最短路径的 `length(path) AS 调用距离`；不得返回单条关系的 `调用深度`，也不得扩展为入口 API 或有序方法路径。
- “某方法的上游调用链”表示从入口 API / 入口方法经过有序方法路径到达目标方法的完整入口链，不得解释为上游可达集合；“A 到 B 的调用路径 / 调用顺序”表示两个明确方法锚点之间的有序方法路径。
- 直接上游调用者的唯一方向是 `(upstream:方法)-[:调用]->(target:方法)`；直接下游被调用者的唯一方向是 `(target:方法)-[:调用]->(downstream:方法)`，两者不得反转。只有查询可达集合时才对 `调用` 使用可变长度遍历；查询有序路径仍使用 `链中下一节点`。

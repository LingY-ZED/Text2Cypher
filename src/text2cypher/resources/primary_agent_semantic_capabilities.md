# 代码知识图谱可检索业务能力

Primary Agent 只使用以下抽象能力规划自然语言检索任务，不推断存储实现细节。

## 代码与归属

- 查询类、方法、接口、实现及它们的归属关系。
- 查询服务、应用、模块与代码元素之间的归属和边界。
- 查询实现关系、返回类型、数量、分组和聚合信息。

## API 与服务交互

- 查询对外 API 入口、请求语义、调用目标和服务归属。
- 查询固定方法或服务的上游来源、直接远程下游和影响范围。
- 查询入口、调用目标和服务之间需要保持对应的事实。

## 调用依赖与路径

- 查询直接调用、接口分派、反向调用者和可达入口。
- 查询完整的上游或下游有序调用路径及其位置顺序。
- 查询变更影响、调用数量和调用关系的聚合结果。

## 消息通信

- 查询消息发布方、路由、队列、消费者和两端服务角色。
- 查询完整消息路径及其中需要保持对应的路由条件。

## 规划边界

- 只规划用户问题需要获取的信息，不生成查询语句或答案。
- 同一记录、同一路径、同一消息路径或同一分组中相互对应的信息必须作为一个检索意图保留。
- 只有多个意图能够独立重算且不需要其他查询结果时，才拆成多个自然语言查询。
